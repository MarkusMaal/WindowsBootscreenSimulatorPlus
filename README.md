# Windows bootscreen simulator plus
Simulate various bootscreens from different Windows versions! Uses WPF as the framework with MaterialDesignInXaml for styling.


## Current functionality
* Windows NT, 98/ME, 2000, XP, Vista, 7 and 8.x/10 boot screen simulators
* Ability to stretch and fullscreen that bootscreen
* Ability to hide/show cursor on the bootscreens
* Ability to switch between server and professional bootscreens for Windows 2000
* Ability to enable fade-in simulation for XP and Vista simulators
* Preset/template system
* About screen

## Note
The project is currently **early** in development and about 85% of the features are not implementated yet, but the basic concept is there.
